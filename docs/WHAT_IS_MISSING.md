  personas, truth engine, autonomy, council, voice, vision, canvas,
  spreadsheet, presentation, creative, productivity, goals, missions,
  replay, fork, durable objects.

  manifest, declarative plugins, MCP bridge, marketplace, self-host guide.
- Companion pack: diary, bond graph, time capsules.

  route manifest to the packages — tested.

## What is stubbed (returns canned data or 501)

1. **Real provider calls.** `packages/providers/src/adapters/*.ts` return
   deterministic fixtures. Real HTTP against Groq, Gemini, Cerebras, etc.
   needs a live network and a provider key. Add one key and set
   `PROVIDER_NAME` to make `/v1/chat` live.
2. **Real Durable Object classes.** The pure state machines for
   `QuotaLedger` and `MissionRunner` are tested. The `class ... extends
   DurableObject` wrappers in `apps/edge/src/do/` are scaffolding.
3. **The React web app.** Only the standalone prototype exists
   (`apps/web/prototype/index.html`). The production Vite + React + Tailwind
   app (`apps/web/src/`) is not built.
4. **File ingestion in the browser.** `pdf.js` page-by-page extraction is
   described in PRD §9.10. The chunking/embedding pipeline exists in
   `packages/library/`; the browser worker that drives it is not wired.
5. **Voice I/O.** Web Speech STT/TTS is described in PRD §14.1. The pure
   session state machine exists; the actual `SpeechRecognition` and
   `speechSynthesis` wiring is not built.
6. **Vision.** Gemini Flash image understanding needs a live `GEMINI_API_KEY`
   and a `<input type=file>` handler. Not wired.
7. **Real D1 / KV / Queues bindings.** `wrangler.toml` declares them.
   The local `.dev.vars` and `wrangler secret put` steps from PRD §H.3 are
   the operator's job, not code.
8. **Real Web Push.** VAPID keys are generated by `pnpm gen:keys`. The
   service worker that receives the push and fetches the note is described
   but not built.

## What the prototype demonstrates

- Paper (light) + Ink (dark) themes, one accent, hairline borders.
- Send → thinking → answer → fact pill → action row.
- The thought drawer (Summary / Reasoning / Trace).
- The facts drawer with two claims, one `CONFLICTED !` showing the
  contradiction.
- The claim drawer opened directly from an underlined phrase.
- Rotating greeting, mode picker, toast on send.

## What the prototype does NOT demonstrate

- Real model output (canned demo reply).
- Real streaming (timed animation, not SSE).
- Real persistence (no IndexedDB).
- Real memory, verification, or sources.
- Real spend tracking (the Rs 0.00 is a static label).

## To go from prototype to live

1. Add one provider key (`GROQ_API_KEY` is the simplest).
2. Wire `apps/edge/src/index.ts` → `handle(req, env, {})` from
   `packages/agents/src/handler-v2.ts`.
3. Replace the scaffolded reply in `handleChat` with a real streaming
   adapter call.
4. Deploy: `pnpm wrangler deploy`.
5. The `apps/web/src/` React app is the long-form project — the prototype is
   already shippable for demonstration.
